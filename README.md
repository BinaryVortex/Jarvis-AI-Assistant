# Jarvis AI Assistant

A virtual assistant inspired by JARVIS from Iron Man, built using HTML, CSS, and JavaScript. This voice-controlled AI assistant can perform various tasks like opening websites, searching the internet, telling time and date, and more.

## Features

- **Voice Recognition**: Uses the Web Speech API for voice commands.
- **Time-Based Greetings**: Greets the user based on the current time (Good Morning, Afternoon, Evening).
- **Website Navigation**: Open popular sites like Google, YouTube, and Facebook.
- **Search Functionality**: Search Google or Wikipedia directly.
- **Time and Date**: Provides current time and date information.
- **Calculator**: Opens the system calculator.
- **Fallback Search**: For unrecognized commands, searches Google.

## Technologies Used

- HTML
- CSS
- JavaScript (Web Speech API, Speech Synthesis API)

## How to Use

1. Clone the repository or download the files.
2. Open `index.html` in a web browser that supports Web Speech API (e.g., Chrome).
3. Click the microphone button to start speaking.
4. Say commands like:
   - "Open Google"
   - "What is the time?"
   - "Search Wikipedia for Artificial Intelligence"
   - "Hey Jarvis" for greeting.
